- Новое главное меню вместо консоли: ник, «Создать игру», «Подключиться», «Настройки». Esc в игре — пауза.
- Настройки графики с наборами «Низкие / Средние / Высокие / Ультра», дальность прорисовки, масштаб рендера, тени, режим окна (F11), FOV, мышь, громкость, счётчик FPS.
- Игра заметно быстрее на слабых ПК, меньше мерцания текстур.
- Ники игроков видны в прицеле.
- Если игра упадёт, рядом появится crash.txt с ошибкой.
