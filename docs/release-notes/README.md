# Что нового — для описаний сборок

Каждая сборка для Windows (Releases → «Сборка для Windows №N») получает описание
автоматически: `tools/release_notes.py` берёт PR, влитые в main с прошлой сборки.

Чтобы под заголовком PR были понятные игроку пункты, добавь их одним из способов:

1. раздел `## Для игрока` в описании PR — 2–5 коротких пунктов без кода и путей;
2. или файл `docs/release-notes/pr-<номер>.md` с теми же пунктами (он важнее описания PR,
   им же можно поправить пункты уже после слияния).

Без этого в описании будет только заголовок PR со ссылкой.
