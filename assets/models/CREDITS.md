# Происхождение моделей

`humans.glb` собирает `tools/models/build_humans.py`.

* Базовое тело (меш, скелет, веса, цели формы) — MakeHuman 1.1,
  https://github.com/makehumancommunity/makehuman. Эти данные выпущены под **CC0**
  (см. раздел C файла LICENSE.md в репозитории MakeHuman), сами модели, полученные из них, свободны.
* Одежда, шлемы, оружие, щиты и все текстуры созданы кодом этого проекта.
* Ассеты сторонних игр не используются.
